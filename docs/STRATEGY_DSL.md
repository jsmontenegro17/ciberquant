# cq-strategy-dsl-v1

Immutable version stores trade_direction(CALL/PUT), indicator_specs, condition_tree, strategy_dsl_version and feature_engine_version. Canonical JSON uses sorted keys, compact separators, normalized Decimal strings and sorted indicator specs; SHA256 hashes the whole definition. Condition child order is preserved. Editing creates a new version under a locked strategy row with UNIQUE(strategy_id,version).

AST leaf: `{ "left": {"type":"FIELD","field":"rsi_14","bars_ago":0}, "operator":"GTE", "right":{"type":"NUMBER","value":"70"} }`.
Group: `{ "operator":"AND", "conditions":[leaf,...] }`; OR also supported. No executable code, arbitrary SQL, eval or arithmetic expressions.

FIELD bars_ago is an integer0–50; it indexes available chronological rows, not synthetic time slots. Gaps are not silently removed/reset; use gap_before/contiguous_run_length when a rule requires continuous history. Both operands' referenced rows must be available by the signal close. Left must be FIELD; right FIELD/NUMBER/STRING/BOOLEAN. NUMBER must be a finite decimal string, max magnitude1e20 and18 fractional places. STRING only C/P/D. Numeric fields: OHLC, candle numerical features, gap_seconds, contiguous_run_length and keys generated by declared specs. direction is STRING; gap_before BOOLEAN. GT/GTE/LT/LTE only numeric; EQ/NE require matching types. Unknown/undeclared fields reject at version creation.

Root depth1, maximum4; total nodes (groups included)50; nonempty groups; at most12 indicator specs (or lower configured Feature API limit). Missing history/null warmup/unavailable row => UNKNOWN, never zero. AND: anyFALSE→FALSE; else anyUNKNOWN→UNKNOWN; elseTRUE. OR: anyTRUE→TRUE; else anyUNKNOWN→UNKNOWN; elseFALSE. UNKNOWN root produces no signal and increments skipped_unavailable. Context stores only referenced field@bars_ago values. Unsupported DSL/feature versions reject, not silently upgrade.

Strategy status DRAFT/TESTING/DISABLED only. These states do not constitute statistical validation. Ownership applies equally to ADMIN. No seeded strategies.
